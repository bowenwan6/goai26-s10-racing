### 数据符合程度：不要把平滑当成“已经准确”

固定范围内全部低位候选点相对假设面的绝对 Z 偏差：

- Start：P50 **2.11 cm**、P95 **9.08 cm**。候选窗口 Z∈(−0.8,−0.12)m，共 424859 点。
- B 后：P50 **2.27 cm**、P95 **16.95 cm**。候选窗口 Z∈(4.25,4.9)m，共 126141 点，包含侧边抬高/不同层的混合观测。
- 以上没有只计算小残差内点，也不是独立地面真值误差；Start 统计使用主路面假设，不把抬高带当作已知真值。完整裁剪源点仍在 `data/*_sources.npz`。
- 本轮新增未知面积：Start 样板外约 **0.204 m²**，B 后约 **0.546 m²**；已确认样板原有约 **0.0856 m²** 未知区也保持不变。黑色空白不代表现场真的有洞。
- B 后侧边有约 0.1～0.3 m 以上抬高回波，不能从这版主平台推断侧边可通行。证据保存在 `data/post_raised_evidence.json` 和源点中，状态仍是未确定。

## 自己打开 MuJoCo / 复核

保留整个目录结构，不能只拿一份 XML。使用已经安装 MuJoCo 3.13.0 的 Python 环境，在本目录运行：

```sh
python check_scene.py
python -m mujoco.viewer --mjcf scene_contact_v1.xml
```

macOS 原生查看器可用环境内的 `mjpython` 替代上面第二行的 `python`。本机可用的环境在 `s10-real-readiness/.venv/`。检查脚本只运行本地球探针，无 ROS/网络/机器人接口。

- `scene_contact_v1.xml`：本轮通过工程检查的候选接触参数。
- `scene_baseline.xml`：默认参数的保留对照，不作为全部测试通过的版本。
- `visual/Start_B_short_combined.ply`、`.obj`：三段可视化合并网格；**不要作为单一凸 mesh 碰撞体**。
- `visual/`、`collision/`：实际场景的相对路径资产。
- `geometry.npz`、`data/B_geometry_preserved.npz`：精确几何；`data/` 还包含固定范围源点/帧编号。
- `mujoco_checks.json`、`interface_checks.json`、`release_checks.json`：机器可读结果。
- `code_snapshot/`：本次构建/检查脚本快照，需回到原工作区及输入数据才能重建；单独解压包可直接查看/运行已有场景和 `check_scene.py`。

本轮使用点云处理技能约束表面分类、受保护边界与源点对照，使用 sim-to-real 技能区分接触实现验证与现场/策略验收。没有把“仿真能加载”当作真实地形准确性的证明。
