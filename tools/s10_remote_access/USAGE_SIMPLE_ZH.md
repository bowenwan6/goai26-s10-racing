## 平时怎么连接

1. 机器人开机，并保持连接能上互联网的现场 Wi-Fi。
2. Mac 正常登录、联网；**ClashX Pro 照常开着，不用关。** Tailscale 后台自动运行，不需要再开一个 VPN App。
3. 打开终端，输入：

   ```bash
   ssh s10-48-remote
   ```

退出机器人终端：输入 `exit`。不需要 Codex，也不要求 Mac 连接机器人的热点。

## 复制文件（可选）

用下面方式把 AGX 上的一个文件复制到 Mac，替换文件路径即可：

```bash
scp s10-48-remote:/机器人上的文件绝对路径 ~/Downloads/
```

注意：原始地图在 106 板卡，不是 AGX；本次入口只连接 AGX，不能直接把 106 的地图路径当作 AGX 路径。

## 打开原来的建图网页（可选）

```bash
ssh -N -L 127.0.0.1:18080:10.21.33.102:8080 s10-48-remote
```

保持这个终端开着，浏览器打开 `http://127.0.0.1:18080`，使用原网页账号。关闭连接按 `Ctrl+C`。网页只转发到本机，不公开发布。

已验证网页入口返回 HTTP 200，没有点击建图或运动按钮；测试隧道已关闭，需要使用时运行上述命令。

## 连不上时

- 先确认机器人开机且有互联网；Tailscale 不能修复机器人 Wi-Fi/网线掉线。
- 不要关闭 Clash、不要删除 SSH 主机密钥记录、不要重启机器人运动程序来尝试修复。
- 若提示需要登录/密钥过期，重新完成 Tailscale 授权；若提示主机密钥变化，先核对设备身份。
- 把报错发来即可。手机端尚未配置；这份指南针对当前 Mac。

本次为避免与 Clash 争用系统 VPN，使用用户态 Tailscale。它不会让所有 App 都自动直连 `100.x` 地址：请使用上面的 SSH 别名或网页隧道。Mac 完全退出用户登录后后台会停止，重新登录后启动；AGX 配置为用户服务开机启动。
