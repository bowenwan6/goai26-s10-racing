# 048 AGX 远程接入条件检查（只读）

先收集事实，再决定是否安装 Tailscale。本工具不实现公网 SSH，也不安装或登录 Tailscale。

## 现场怎么用

1. 确认实物是 **048**，将运行 Codex 的电脑连接 **S10 PRO-048-5G**。机器人继续保留现场 Wi-Fi 上联；不要拔线或重配网卡。
2. 告诉 Codex“已连接 048”。先核对本机地址、已信任的 SSH 主机身份；多台机器人会复用 `.102`。
3. 从本目录运行下面命令（通常由 Codex 执行）：

   ```bash
   bash collect_from_mac.sh --confirm-048
   ```

   若使用已有专用密钥，追加 `--identity /绝对路径/现有私钥`；脚本不读取或复制私钥内容。SSH 密码由本地终端交互输入，不能放进命令、文件或报告。

4. 报告只保存在电脑的 `s10-real-readiness/artifacts/s10-remote-access/<时间戳.随机后缀>/agx-report.txt`。新目录权限为 700，报告默认 600，沿用现有 Git 忽略规则。中断会保留部分报告，不覆盖旧结果。

不带 `--confirm-048` 仅显示用法，不连接；`--no-probes` 只读本地状态，不发起显式外网探测。正常采集通常几十秒，探测失败时可能接近 3 分钟。每项检查有超时；总采集预算约 180 秒，预算耗尽跳过后续检查并返回非零。SSH 建连和人工密码输入不计入该预算。

主机密钥使用 `s10-48-agx`，严格拒绝未知或变化的密钥。如果当前 Mac 只保存了 IP 对应的记录，先核对它与已验证的 048 指纹是否一致，再决定是否复用；脚本不会自动添加信任、删除旧记录或关闭校验。

这台 Mac 已使用严格主机密钥校验成功登录当前用户确认的 048，信任记录保存在 `10.21.33.102` 下。因此本机实际执行时追加 `--host-key-name 10.21.33.102`，复用现有信任，不复制或改写 `known_hosts`。

## 收集什么

- 设备名、系统版本、ARM 架构、当前账号和组、空间、时间同步状态。
- 当前 Wi-Fi 连接、信号、网卡驱动/链路协商、地址、DNS、默认/策略路由、热点回程路由、前后两次接口计数。
- SSH/8080 监听地址、相关服务状态、TUN 设备、已有防火墙规则（仅在当前账号可读时）。
- 现有 Tailscale 版本和经过白名单过滤的本机状态；不打印其他节点、用户或登录授权链接。
- AGX 自己发起的有限 DNS、ICMP、HTTPS 探测。忽略 curl 配置文件和代理环境变量，不发送认证资料，不下载执行脚本，不输出网页内容、Cookie 或重定向地址。若已有 Tailscale，再做一次有超时的 NAT/UDP/中继探测。

不扫描附近 Wi-Fi、不重连网卡、不提权、不读取保存的 Wi-Fi 密码、私钥或登录令牌；不导出原始环境变量或完整应用配置；不进入 103/106，不改 DNS/路由/防火墙/SSH/ROS，不重启服务、不发运动命令。正常 SSH 登录及外网请求可能产生系统/服务器日志，这是诊断本身的正常副作用。

报告包含网络名、IP、主机名等内部资料，应私下保留，不上传公开仓库。

## 怎么解释

- Wi-Fi 已连接不等于有互联网；结合地址、路由、DNS 和 HTTPS 判断。
- 仅 ICMP 失败可能是禁 ping，不能直接判定断网。
- HTTPS 返回 301/403 等只能说明收到了相应响应，不能证明 Tailscale 控制通道可用；脚本不关闭 TLS 证书验证。
- `command_exit=0` 和脚本退出 0 只表示命令/采集完成，不代表项目全部通过。权限不足、命令不存在、预算耗尽都按未知处理。
- 端口 22 在监听不等于密码/密钥策略安全；本脚本未提权核查 sshd 配置、Match 规则或管理员权限。
- 两次接口计数和短时 HTTPS 检查不能排除偶发掉线；本脚本不收集内核历史日志，也不出“长期稳定”的结论。
- 若未安装 Tailscale，仅能评估安装前提。后续需要单独完成管理员授权、账号登录、最小权限规则及**电脑切换其他网络后的真实 SSH 验收**，才算完成。
- 远程维护链路不能替代现场遥控和急停。

命令依据：[Tailscale CLI（status/netcheck）](https://tailscale.com/docs/reference/tailscale-cli)、[NetworkManager nmcli](https://networkmanager.dev/docs/api/latest/nmcli.html)。
