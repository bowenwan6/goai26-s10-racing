# 每次停稳的“静止基准复零”

2026-09-15：已部署至48号102网页与106现场助手。不是硬件校准、停车按钮或安全认证功能。

## 手机操作

1. 手机连机器人热点，打开 `http://10.21.41.1:8080/` 并登录，进入 **IMU／停稳诊断**（`/imu-check`）。部署重启后需重新登录、刷新一次。
2. 找到页面上方 **每次停稳：静止基准复零**。由手柄安全停稳，退出外部 policy/导航；不要为了检查而关闭必要的平衡控制。
3. 每次重新勾选两项现场确认，点 **静止基准复零（约13秒）**。
4. 保持不动：前10秒采样、后3秒独立验证。进度条由106实际任务提供；按钮锁定，不能重复启动。
5. 完成后同时看原始值和相对零点值。**相对值仍会小幅波动**，不是把每一帧硬设为0。加速度、姿态、原始曲线和原始录制不归零。
6. 开始移动前点 **开始移动／清除零点**。按钮只清除参考，不能控制机器人。下次停稳后重新复零；可导出当前参考JSON。

参考最长有效120秒。检测到明显移动、数据过期、控制状态变化、队列丢弃、源时间异常或服务重启会失效。缓慢平移等情况不保证自动识别，所以必须主动清除，且这个参考不能用于放行运动。

## 为什么可能只完成IMU参考

- IMU静态均值用于显示角速度相对变化。
- 本体速度使用 `/MOTION_INFO`，不是网页低频日志的三个舍入数值。第三项是yaw转向速度，不是Z速度。
- 只有新鲜、足够覆盖、state=17、具有持续数值更新且验证稳定的样本，才显示本体相对静止参考。这里的统计筛查不证明各速度分量的估计准确或全部上游数据有效。
- Idle／趴下状态、冻结数值或资料不足时，本体速度框明确显示 **未复零** 和原因。绝不因为IMU参考建立就把这一路填0。

**本体控制器、SLAM、定位、WP和切图检查不读取这些相对值。** 这个按钮减轻的是本页观察静态偏移的困难，不修复厂商上游缓存，也不解决原门禁的全部误判。硬件校准状态仍为“未验证”。

## 断线、重试与保存

- 13秒任务在106后台运行；手机锁屏/断线不会取消采样，恢复后显示任务结果。断线期间不显示可用的相对值。
- 同一请求编号只创建一次任务；同时来的不同请求互斥。失败的新请求不会恢复上一份零点。
- 与60/180/300秒限时检查互斥；限时检查始终保存原始数据，不保存“看起来归零”的伪原值。
- 参考与采样证据保存在 `/var/opt/robot/data/s10_field_assistant/imu_diagnostics/zero_references/`。`<id>.json`为状态，`<id>.evidence.json`为本次已收到的采样值及拟合/验证信息；不是硬件原始串口包。
- 服务重启会把旧参考标记失效，不能跨开机沿用。
