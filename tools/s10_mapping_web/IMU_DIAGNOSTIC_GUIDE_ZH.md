# IMU／停稳诊断使用与交付说明

2026-09-15更新：**已部署102/106**，维护连接使用 `ssh s10-48-remote`。用户已完成一次300秒真实静止记录。另新增[13秒静止基准复零](IMU_ZERO_REFERENCE_GUIDE_ZH.md)，仅诊断显示；新版28项真实网页只读检查通过，真机按钮采样仍待现场确认，不冒称硬件校准完成。

## 手机怎么用

1. 手机连接`S10 PRO-048-5G`，打开现有首页`http://10.21.41.1:8080/`，登录。
2. 点新增蓝色 **IMU／停稳诊断**；也可打开`/imu-check`。看到角速度、加速度、X/Y/转向反馈及命令曲线。
3. 图上显示源读数，波动不会自动归零。数据源过期时显示断流；没有新鲜IMU不能开始基线采样。校准状态默认“未验证”，不误报“已校准”。
4. 让机器人安全站稳，退出外部policy/导航，手柄可接管；勾选两项确认。保持必要的原厂平衡控制，不随意关闭执行器。
5. 默认选180秒，点击 **开始静止检查**。也可选60或300秒。进度条、累计样本和按钮禁用状态表示后台还在工作；不要重复点击。
6. 期间可添加“刚停稳/刚移动”人工事件。运动必须由现场人员操作，网页不控制机器人。
7. 到时自动结束。可点“结束并保存”提前结束，状态会明确为部分采集；这个按钮不停车。
8. 在历史记录里查看中文摘要和完整技术数据；下载ZIP，在电脑打开`report.html`看离线10秒均值趋势，或用CSV/JSONL检查完整已接收消息。

第三项Motion Vel是yaw转向速度，不是竖直Z速度。IMU加速度可能含重力，不能期待静止时三轴都为0。

## 本版实际实现

- 现有首页入口、原登录/CSRF和原8080端口；无新公网服务、无CDN依赖。
- 复用106持久field worker，独立`imu_diagnostics`组件；200Hz历史配置不作为实测保证。诊断启用时读取每条可用的`/IMU`及`/ODOM`消息，原field低频预览与保护逻辑不变。
- 原生收到消息写JSONL；录制期间保留ROS序列化CDR的base64及解码字段，不将驱动发布值冒称未经处理的硬件原始读数。
- 约10Hz min/max/均值包络供页面显示；完整消息用于10秒窗口均值/标准差和时序统计。AGX与106维持单条受限SSH数据流，多手机共享后台采集。
- 106文件位于现有field根目录下的`imu_diagnostics/<session_id>/`；默认完整路径为`/var/opt/robot/data/s10_field_assistant/imu_diagnostics/<session_id>/`。
- 每次完成生成`manifest.json`、`status.json`、`samples.jsonl`、`samples.csv`、`report.json`、离线`report.html`及`diagnostic.zip`。AGX代理带范围校验的下载，**本版不额外在AGX自动备份一整套数据**；下载后由操作者保存。
- 手机/AGX链路断开不结束106的限时任务。106重启后原RUNNING任务标记INTERRUPTED；仅已落盘部分保留，不保证断电前尾部样本完整。中断记录暂不自动生成ZIP，可从106取出已保存源文件。
- 单实例、开始请求编号幂等、256MiB任务上限、2GiB磁盘保留；队列溢出明确计数。记录错误/缺测不触发校准或原功能放行。

## 尚未声称完成

- 手机无WAN冷启动、峰值负载下的长期采集完整性；部署和已有300秒真实记录不替代这些验收。
- 传感器具体型号/固件、温度字段、工厂校准状态、Motion Vel上游和实际单位的自动识别。不可得时保持“未验证”，不伪造字段。
- 完整加速度标定、零偏写回、估计器修复、App原停稳门槛修改。新按钮只是本次相对参考，不属于上述硬件/控制修复。
- 源发布者真正的每包不丢；没有硬件序号只报告接收间隔/本地丢弃和缺测，不编造端到端丢包率。

## 部署时的安全顺序

1. 先恢复SSH，核对102/106设备身份和当前部署文件哈希，确认不存在进行中的原建图保存、field作业或诊断任务。
2. 备份机器人上受影响的现版文件；不能直接覆盖可能与本地不同的队友修改。
3. AGX需新增`imu_diag.html/js`，更新`index.html`及`server.py`。106需新增`imu_diag.py`，更新`field_robot.py`、`field_worker.py`、`robot_backend.py`。102的其他Python依赖与106现版需核对兼容；不复制凭据或修改厂商环境。
4. 新文件暂存校验后切换；仅在无进行中任务的维护窗口重启` s10-field-worker.service`与AGX用户`s10-mapping-web.service`。**不重启IMU、定位、SLAM或控制器。**
5. 核对登录→主页按钮→新鲜IMU→短采样→报告导出→手机断线恢复，记录CPU/内存/延迟；若影响原任务，停新增诊断并回滚本次文件。
6. 回滚只恢复上述备份文件，不删除`imu_diagnostics`或已有field任务/地图数据。
