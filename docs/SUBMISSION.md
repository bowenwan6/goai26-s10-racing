## Reproduction entry points

The complete environment, build and run procedure is in the root `README.md`. The shortest
review path is:

```bash
git clone https://github.com/bowenwan6/goai26-s10-racing.git
cd goai26-s10-racing
git clone https://github.com/DeepRoboticsLab/goai_embodied_future_material.git \
  upstream/goai_embodied_future_material
docker compose build
S10_UPSTREAM_OFFLINE=1 docker compose run --rm s10 scripts/setup_upstream.sh
docker compose run --rm s10 scripts/build.sh
docker compose run --rm s10 scripts/verify_install.sh
docker compose run --rm s10 scripts/run_race.sh --headless
```

The official SDK repository is access-controlled by the organizer and is therefore referenced at
the validated commit rather than copied into the submission.

## Required perception visualization

On native Ubuntu 24.04 with a graphical desktop, run:

```bash
scripts/run_race.sh viz:=true rviz:=true
```

The bundled RViz view simultaneously displays the horizontal `/scan` rays, the 8x64 lidar point
cloud and the 13x9 height-map points used by navigation. Visualization is optional during a timed
headless lap because it does not alter control inputs or scoring.

## Code-package contents

The package generated by `scripts/package_submission.sh` contains only Git-tracked material:

- `src/`: perception, navigation, strategy router, launch files and configuration;
- `integration/`: reviewed patches for the official SDK controller;
- `policy/`: Gate 16 models/manifests and the fail-closed stairs57 asset;
- `scripts/`: setup, build, verification, run, capture and packaging commands;
- `docker/` and `compose.yaml`: pinned Ubuntu 24.04/ROS 2 Jazzy environment;
- `docs/`, `README.md`, `LICENSE` and package metadata;
- tests and optional training/contract scaffolds needed to audit model interfaces.

It does not contain the organizer's SDK, `upstream/`, build products, credentials, logs, raw
telemetry, replay frames or video. See `THIRD_PARTY.md` for dependency/data boundaries and
`OPEN_SOURCE_PLAN.md` for the open-source plan.
