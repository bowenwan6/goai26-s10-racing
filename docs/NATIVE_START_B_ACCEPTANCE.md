# 官方内置策略：Start 与 Area B 验收计划

2026-09-17。范围为现有 v3 SLAM、我们的 waypoint follower、我们的 router，以及机身官方原生运控。平地使用导航平地 0x3002，楼梯使用导航楼梯 0x3003。此次不使用厂商目标点规划器，不启动外部 SDK actor。

用户已授权先实现；用户稍后把机器人挪到 Start。当前阶段只实现、离线测试和实机只读预检。

| 阶段 | 操作与验收证据 | 进入下一阶段的条件 |
|---|---|---|
| A：实现与静态验收 | router 按明确路段选择 gait；切换期间保持零速，收到新鲜且稳定的 gait 反馈才放行；输入过期、定位丢失、控制源冲突、取消均停止并锁定；记录候选与实际输出 | 自动化测试通过；真机导入与消息定义匹配；默认启动没有运动发布器 |
| B：官方策略调用验收 | 现场在净空平地，操作员先进入原生 RL 控制；程序分别请求 0x3002/0x3003 并记录 MOTION_INFO；随后每个模式进行限定时间、距离与速度的小范围响应测试 | 两种 gait 均得到请求之后的稳定反馈；小速度输入方向正确、取消及停止有效；不能仅凭历史日志或订阅端存在通过 |
| C：Start 平地测试 | 实机 v3 全局定位稳定；校准路线地面高度与 ODOM 参考点；先运行 Start 的短段，记录轨迹、误差、速度、gait 与停止原因 | 所有目标按顺序达到 XY≤0.20m、Z≤0.20m；无人工纠偏，无持续偏离；正常结束保持零速；重复两次通过 |
| D：Area B 测试 | 先测试首段楼梯，再扩大到整个 B；在经确认的楼梯入口前完成切换，整段楼梯保留楼梯模式，上平台后切回平地 | 入口切换有反馈，楼梯内无意外切回；不跳过高度不同的目标；终点到达并停止；重复两次通过 |
| E：Start→B 串联 | 使用同一份已验证路段配置，依次执行 C、D，记录完整 rosbag 与 JSON 状态 | 两次连续全段成功，所有前置项仍有效；报告中单列人工接管、失败与未验证项 |

初始测试速度上限：平地 0.20m/s、楼梯 0.15m/s，横移 0.05m/s、转向 0.20rad/s。这些是保守测试设置，不是已经校准的实机性能参数。楼梯速度不足以通过时停止并重新评审，不自动加速或倒退重试。

接口调用试验与路线试验独立：先证明本机官方策略确实响应，再允许 follower 驱动路线。姿态不对、状态不明或输入缺失时不能发送切换；程序不自动起立，不解除急停，不调用未知枚举的服务。
