## 与原程序的差异

模型 metadata 明确给出的默认姿态是：髋外展 0，前髋 −0.30／前膝 0.60，后髋 0.30／后膝 −0.60 rad。原 runner 使用髋外展左右 ±0.05、髋／膝绝对值 0.35／0.65。副本同时对齐观测减去的默认角和输出加回的默认角，并把轮关节 Kd 从 0.8 改为模型的 0.6；保留原有进入 RL 时的增益渐变。

48 号实测 `/IMU_DATA` 姿态已经是弧度，与 `/IMU`、`/IMU_103` 四元数解算一致。副本移除重复度转弧度，IMU 订阅改用 SensorDataQoS。另让 `main` 接收 ROS 命令行参数，使测试输入和 dry 关节输出的话题映射实际生效。

关节顺序、动作缩放、腿关节 Kp/Kd 与模型一致。硬件关节方向、零位补偿和起身轨迹沿用当前官方 SDK；闭环效果仍需现场验收。

具体补丁与模型 metadata 见 [部署记录目录](../artifacts/s10-speedturn-48-20260912/)。

## 现场要做什么

可直接双击 [start_s10_speedturn.cmd](../scripts/start_s10_speedturn.cmd) 打开 Windows 手动前端。标题是“自定义 ONNX speedturn2000”；旧 `start_s10_gui.cmd` 仍打开本体控制窗口。打开窗口不会自动发运动命令。

- **起身**：连接、检查反馈、起身并进入 ONNX 支撑，保持到用户点趴下。
- **前进、后退、左移、右移、左转、右转**：显示“支撑中”后可操作。按住移动，松开、移出按钮或切走窗口回零；回零仍保持支撑。
- **趴下**：速度回零后完成趴下，退出本次控制；可以再次点起身。
- **空格／停止移动**：速度回零，保持支撑。
- **中止控制／关闭窗口**：请求阻尼并退出，不等于正常趴下或硬急停。

默认输入 20%，按用户要求允许直接填写 1%–100%；修改后下一次按方向按钮生效。100% 是前端定义的归一化输入 1，沿用 SDK 示例 runner 的硬编码换算：前向目标 1.5 m/s、侧向 0.5 m/s、转向 0.6 rad/s；不是 ONNX 声明的范围或硬件满量程。默认 20% 对应前向 0.30 m/s、侧向 0.10 m/s、转向 0.12 rad/s；这是指令目标，实际效果由模型与地面条件决定。原有姿态、关节速度／力矩等反馈保护仍生效，可能提前中止过大的输入。移动命令超过 0.35 秒未更新会回零；连接心跳丢失超过 1 秒会请求阻尼退出。长时间控制在内存中只保留最近约一分钟采样，阶段日志写入磁盘。
