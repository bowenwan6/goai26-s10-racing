# 人工复核区与三维回放

队友首次接手请先阅读 [录制复核与重建交接](../../docs/S10_RECORDING_REVIEW_AND_RECONSTRUCTION_ZH.md)，其中说明原始数据/SDK 的获取、机器路径配置、首次缓存生成和多人标注规则。本文是已有本机环境的操作速查。

入口：[复核队列](http://127.0.0.1:8767/review_queue.html)；[38 cm 高台示例](http://127.0.0.1:8767/viewer.html?id=gait_20260909_151135_f45a816f4062&t=11&end=15)。

请使用 **8767** 的标注服务。原 **8766** 是静态预览服务器，不支持保存和原始采样读取。

## 使用

1. 从候选通行、内部片段或待确认问题中选择一项。
2. 播放或循环选区（自动带前后各 2 秒），拖动 3D 视图旋转，滚轮缩放；也支持方向键旋转、加减键缩放。前后点云与机器人可分别隐藏。
3. 对动作关键区点击“加载精细回放”。最多读取 20 秒；长选区改为游标附近的一段，页面注明实际加载范围。
4. 调整起止源时间，选择地形、动作、方向与结果。填写障碍编号与所属连续通行编号，可以关联连续梯段和中间平台。看不清的项目保留不确定。
5. “确认并保存”或“保存为无法判断”将人工记录写入本目录 `human_reviews.jsonl`，首次保存时创建。刷新或重新打开后，可在“已保存标注”继续编辑；“导出全部人工标注”下载当前有效标注的 JSON。

“合并前一候选区间”扩展起点，检查后再保存；“在当前位置拆成两段草稿”将原人工条目撤回（若存在），保存两段 pending 草稿，并重置动作、方向、结果，需分别复核。“撤回此标注”不删除历史记录。

人工标注是**独立覆盖层**，没有改写 passages/segments 的自动候选。原报告和总览的 pending 数量是旧自动索引状态；复核页显示的是人工记录状态。后续整理应同时读取人工文件，不能只读取原 CSV，也不能把人工确认等同于合格专家样本。

## 显示和采样含义

- 所有主 JOINTS_DATA 的 5 秒窗口：185 个窗口中位频率约 200 Hz，65 个约 50 Hz；没有发现稳定 100 Hz 档。个别整段平均约 100 Hz 是两档混合。`JOINTS_DATA_10HZ` 为独立的约 10 Hz 话题。
- 总览仍使用现有约 10 Hz 动作、约 2 Hz 点云缓存。精细回放读取原始主关节时间戳，在相邻 IMU/MOTION_INFO 中查找有效样本，用 SDK 运动学计算骨架；不插值造出新测量。浏览器屏幕帧率与数据源频率不同。
- 精细点云读取原始约 10 Hz 的帧，每帧最多抽样 6,000 点，不复制 bag。跨流源时钟仍未校准；各窗口保留源/接收时间。精细模式仅在源时间下生效。
- 三维视图按点云声明的 base_link、IMU 姿态和 SDK 骨架显示。每段录制内部使用同一初始航向原点，不同录制之间没有共同世界原点，机身 XYZ 固定；前后点云分别取近邻帧，仅施加姿态旋转，**不补偿平移、不积累地图**。安装外参仍需核对。轮子画为示意圆，未渲染完整网格或显示累计自转相位。
- 缺失的 IMU/关节不延续为旧姿态；没有相邻点云时不画旧云。该视图支持动作和地形阶段复核，不证明逐轮接触、世界位移或障碍真实尺寸。

## 启动与验证

从项目根目录运行：

```powershell
.venv-win/Scripts/python.exe -B artifacts/s10-recording-review-20260909/review_server.py
```

服务只监听 127.0.0.1:8767。原始数据以 SQLite `mode=ro` 读取；人工文件逐次追加修订并刷新到磁盘。索引和原始文件未重写；未执行地图配准、地形重建或训练。

检查：

```powershell
.venv-win/Scripts/python.exe -B artifacts/s10-recording-review-20260909/review_server.py --selfcheck
```

自检覆盖临时日志的 HTTP 保存/读取、整批非法标注不写入、修订与撤回保留历史、200/50 Hz 原始采样细节，以及缺流时不延续旧姿态。真实人工文件不用于测试。

浏览器已检查：服务连接、3D 点云/骨架显示、选区播放、源时间跳转，以及高台 9–17 秒的精细加载（1,600 个原关节样本、前后点云各 83 帧）。人工确认由使用者完成。

代码复用 `build.py` 的回放和 `review.py` 的消息解析/点云抽样；没有新增依赖。
