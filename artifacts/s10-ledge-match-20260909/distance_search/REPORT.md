# 距离与动作阶段复核

**只将高台移近 6 cm，动作和时间均保持不变，当前 MuJoCo 模型成功上台。** 原始距离侧翻，不能再仅凭接近阶段距离 RMSE 小就排除前后距离问题。该修正是仿真匹配结果，尚不是雷达外参标定结果。

## 对照结果

|---|---:|---:|
| 9 秒机身原点到台沿 | 57.45 cm | 51.45 cm |
| 同时刻前轮外缘到台沿 | 21.51 cm | 15.51 cm |
| 高台高度 | 38 cm | 38 cm |
| 关节动作时间偏移 | 0 | 0 |
| 首次左前轮触台沿 | 12.361 s | 12.141 s |
| 首次右前轮触台面 | 12.861 s | 12.841 s |
| 首次左前轮触台面 | 13.241 s | 13.221 s |
| 两后轮首次触台面 | 未发生 | 13.481 s |
| 结果 | 13.561 s 倾角超过 60° | 四轮越过台沿，末段站稳 |
| 12–14 秒机身姿态误差 RMSE | 50.79° | 11.82° |
| 9–12.2 秒与原点云距离 RMSE | 1.82 cm | 6.99 cm |

![相同动作：上排原始距离，下排高台移近6厘米](before_after.png)

接触日志显示，原距离下机身于 12.181 秒先碰到台沿，左前轮到 12.361 秒才建立台沿接触。修正后左前轮触台提前约 0.22 秒；后轮能够在后续动作中接上台面，最后 1 秒的机身倾角为 0.08–1.66°。这支持“距离改变接触时机和支撑过程”的解释。两种试验除高台沿水平方向移动 6 cm 外，机器人初态、关节参考、PD参数、平台高度和其他物理参数一致。

这不等于实机与台沿的真实距离已被纠正了 6 cm：成功方案与原点云距离反而偏离更多。尚需核对点云所声明的 `base_link` 与 SDK 机身原点是否一致，也可能存在碰撞模型或接触几何误差。不能将仿真成功作为选择外参真值的唯一依据。

## 实录的动作阶段

使用 16 个关节反馈和 IMU，经 SDK 运动学计算四轮相对机身的位置：

- 12.500 秒：俯仰开始低于 −10°，进入明显抬升。
- 12.845 秒：最大抬头，俯仰约 −40.02°。
- 13.060 秒：前轮相对后轮的平均高度差最大，约 34.55 cm。
- 13.190 秒：俯仰回到 −10°以上，开始回平。
- 已有人工标注将 12–14 秒标为完成上台。

![十二个腿关节随时间变化](joint_phases.png)

关节加 IMU 能定位抬腿、抬升和回平阶段，单靠关节位置不能证明轮子在世界坐标中已经接触台面。交互对照因此让左右两边都以机身原点居中：左侧是真实关节骨架、IMU和同步前后点云；右侧是仿真骨架和高台。没有伪造实录机身的完整世界轨迹。

## 搜索与复现

粗搜索共 77 组：前后距离 ±15 cm、步长 3 cm；动作延迟 ±0.3秒、步长 0.1秒。22 组通过当前四轮越台、机身高度与无大倾角判据。保持时间不变再做 11 组距离细测：移近 5.5 cm 失败，移近 6.0、6.5、7.0、7.5 cm 成功。这个边界仅对应本次模型和初始条件，未做多次扰动鲁棒性测试。
