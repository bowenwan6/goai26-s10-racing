先打开本目录的 **interactive.html**；不需要互联网。拖动旋转，点击图例显示源点、旧版、未知区或线框。开启“全部源点”后，点“源点全高”查看全部高度。

## 已做什么

这次只处理 Start 中一块 **5×2.5 m** 的路面与弯曲抬高边界：map X=3～8 m，Y=−1.1～1.4 m。矩形边是本次裁剪线，不是道路真实外边。

- 灰蓝路面：约 **1.92° 微坡**的局部统一平面，不是水平板。
- 金棕抬高带：由低位回波剖面拟合的独立非平面过渡，没有与路面一起压平；颜色表示结构类别，不是照片贴图。
- 受保护曲边：从截面变化提取，不用旧版 20 cm 占据格定义外轮廓。最终弦段最长约 4.25 cm；这是表示尺度，不是测量精度。
- 红色小块：缺少近邻同层观测或超出剖面支持范围的区域。它们只是交互页里的标记，**不在导出网格里**，也不能解释为现实存在小洞。

尚未确认抬高带的材质，不能将其称为尺寸已测准的混凝土路缘石。照片仅辅助理解环境，未精确配准或用于推算尺寸。

## 数据与方法

上游重新读取了 Start 附近 114 个原保存帧，局部缓存共 782,749 点；没有在旧版粗缓存上插值冒充更细观测。只用已有优化位姿变换一次，不做去畸变或传感器重标定。

路面由约 3.5 cm 的空间均衡样本锚定同层平面；曲边采用 2.5 cm 剖面分析；抬高带采用同一边界内的局部单调剖面假设。没有执行全局 Laplacian、Taubin 或双边滤波；当前分区不需要靠全网格滤波获得平面。

最初选择的更深内侧包含遮挡和不稳定边界，因此按原计划“约 3×5 m、按实际边界调整”的原则，收在前侧 5×2.5 m。没有把那些不稳定候选悄悄删除：53 个边界候选及其误差仍在 `boundary_constraints.json` 中；更深区域不作为本次已完成部分。

| 检查 | 结果与含义 |
| --- | --- |
| 网格 | 2669 个三角面，导出中 1625 个使用顶点；不是用面数声明精度 |
| 原 B / 原图 | 120 个输入文件哈希复核一致，包括 v3 full_cloud、读取的保存帧、位姿、原 B 几何和碰撞文件 |
| 主几何与 PLY | 无自交，边/顶点流形，面朝上；开放地形不强制水密封闭 |
| 平面内部 | 共用平面参数；数值偏差约 10⁻¹⁵ m，仅说明实现一致 |
| 表面射线 | 2669 条全部命中，最大数值误差约 1.07 μm；只检查网格实现，不是物理测试 |
| 未知面积 | 路面约 0.0844 m²，另有约 0.0012 m² 内侧小片；未补成地板 |
| 路面与源点偏差 | 固定路面范围、Z∈(−0.7,−0.15)m 的全部 64,491 个候选点：绝对高度偏差 P50≈2.47 cm，P95≈10.13 cm，最大≈27.68 cm；没有仅报告小残差内点 |
| 抬高带与源点偏差 | 所在区域相对平面高度 (−0.12,0.35)m 的全部 2030 个候选点：P50≈5.42 cm，P95≈17.96 cm，最大≈31.66 cm |
| 曲边拟合代价 | 样板内 33 个候选的 Y 向偏移 P50≈2.60 cm，P95≈7.25 cm，最大≈9.59 cm；包含样板外侧在内全部 53 个候选，P95≈17.73 cm，最大≈32.99 cm。Y 向偏移不等于法向精度 |

因此，这版改善的是**分面、弯边和表达方式**，不能说平整后的面已经证明是厘米级真实地形。抬高带的局部纵向变化和材质仍待确认；不因这些残差重新归因 IMU 或扩大排查。

### 导出兼容性说明

- 建议将 `assets/Start_sample.ply` 或 `geometry.npz` 作为双精度几何主文件。
- `assets/Start_sample.obj` 已用完整 float64 往返精度写出。当前 Open3D 的 OBJ 导入器会缩为 float32，最大坐标差约 **0.000263 mm**，其近共面 3D 相交判据报告 60 对候选。
- 这项警告没有被隐藏：独立检查导入后**所有**三角形的 XY 投影，正面积重叠为 0；PLY 的原生相交检查也为 0。详细数值在 `export_checks.json`。这不替代未来 MuJoCo 的实际导入与接触检查。
- 为避免未知掩码对角接触造成非流形顶点，仅把这些掩码保守扩大 0.1 mm，增加不建模面积约 0.000618 m²；没有移动真实结构候选曲边。

## 文件

- `assets/Start_sample.ply`、`.obj`：合并样板。
- `assets/pavement.*`、`raised_transition.*`：分层资产。
- `geometry.npz`：顶点、三角面、类别、平面、剖面、曲边。
- `sources.npz`：固定裁剪源点、帧编号、区域类别及残差。类别是几何位置，不是人工真值标注。
- `interpolation_mask.npz`：2.5 cm 检查探针与同层观测最近距离。
- `surface_patches.json`、`boundary_constraints.json`：面、边与假设。
- `checks.json`、`export_checks.json`、`originals_unchanged.json`：几何检查、导出检查和输入保护证据。
- `display_settings.json`：同尺度比较相机、裁剪和 B 仅展示平移参数。
