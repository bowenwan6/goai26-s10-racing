# 企业会谈准备清单

报告正文已经定稿且没有待填写内容。本清单用于会谈时快速确认企业能够提供的资源及双方下一步安排。

## 1. 技术知识与指导

- 强化学习：奖励与课程设计、domain randomization、训练稳定性、sim-to-real。
- 导航：LiDAR 近场建图、状态估计、局部规划、停滞恢复。
- 轮足机器人：动力学、执行器与接触、系统辨识、安全阈值和现场调试。
- 建议会谈结果：确定技术联系人、评审频率和第一批需要共同诊断的日志。

## 2. GPU 与硬件设施

- 并行仿真、模型训练和批量回放所需的 GPU 类型、额度与使用周期。
- S10 或相近轮足平台、机器人端计算单元、LiDAR、IMU 和控制接口。
- 可调台阶／楼梯／坡道、保护区、牵引、急停、同步采集设备、电池和备件。
- 建议会谈结果：确定可用设备、场地、数据接口、测试时间和安全负责人。

## 3. 开源或闭源模型

- 预训练运动策略、地形感知模型、导航模型、router 或视觉语言／语言模型。
- 权重或 API、输入输出定义、推理延迟、部署环境、许可与技术支持范围。
- 建议会谈结果：选出可在本任务日志或仿真环境中进行初步评估的候选模型。

## 4. 联合工作的首批产物

1. 覆盖成功与失败的同步实机数据集。
2. 仿真与实机参数及延迟对照表。
3. 连续路线测试与故障处置流程。
4. 轻量 router 或其他候选模型的离线评估结果。

## 5. 建议携带的材料

- 完整仿真路线视频，以及高台阶接管和交还的短视频。
- 系统层级图、真实接口需求和 13×9 高度图示意。
- 45-case 原始结果及成功、失败轨迹各一条。
- 当前 GPU、机器人、传感器、场地和测试时段需求清单。
