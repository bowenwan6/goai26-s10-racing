# 航点返回复测

入口：[现场助手](http://10.21.41.1:8080/field) → **⑤B 航点返回复测**。
只需手机连机器人 Wi-Fi＋原厂手柄；不需要互联网或 Codex。

## 测的是什么

用手柄离开，再回到**同一实体标记附近**，比较两次定位坐标。不要求分毫不差归位，也不要求原朝向。
不是让机器人自主走回 WP0，也不能只让网页“距离归零”来证明回到了原地。
测到的差值包含真实停靠位置差、站姿变化和定位误差；不等于地图的绝对精度。附近快速对照不能单独判断纯定位误差；尽量对准标记时可以观察重复性，但仍包含人工残差。

## 操作步骤

1. 恢复保存 WP0 的原会话。确认实际加载的是同一 v3；已是该图就不必重新加载。
2. ③30秒检查在定位异常时也可诊断；但必须检查通过并人工核对叠合后，才允许标点/复测。掉定位、重启或超过30分钟，需要重新检查；定位会话改变时先①重新自检。
3. 首次标 WP0 时，选可复认的地标（允许粘贴时可用胶带十字），记录机身哪个位置对应标记。某只脚的位置不能稳定代表机身位置；不要求每只脚完全一样。
4. 用原厂手柄离开，再回到该**实体标记附近**停稳。网页距离仅辅助接近，不必调成0；朝向可以不同，软件会记录角度差。
5. 在⑤B选择 WP0；同名点核对编号/日期。选择“附近快速对照”或“尽量对准标记”。对点说明选填；尺量残差没测过就留空，不填假0。
6. 确认其他策略退出并手柄可接管，勾选本次已到标记附近且停稳。点击“已到标记附近并停稳，复测5秒”。只要求本次采样期间保持不动，不要求和上次完全重合。
7. 查看水平偏移（cm）、带正负的高度差（cm）、朝向差（°）。原WP不变，每次复测独立保存。每次再测都需要重新确认。
8. 下方历史“查看/下载”可取该次 JSON、原始采样 JSON 和 XY 偏差放大图 SVG。⑥重新汇总，下载 `waypoint-revisits.json` 保存整会话成功及失败记录。

## 怎样理解结果

- 位置参考线为水平10 cm、高度±10 cm。朝向差独立显示，不以朝向差大拒绝保存，也不把转身当成位置复测失败。这些均**不是导航安全或现场尺寸验收标准**。
- Z是定位参考点高度差，不是地面高差。抬高/降低机身或站姿改变都会影响它。
- 参考点/外参未核实时，允许保留同一参考语义的诊断对照，但明确显示“尚未核实”，不能宣称机身绝对精度通过。
- 原点或本次采样未通过既有静止质量规则、当前定位无效/过期、坐标系/地图/标定配置不同会拒绝比较。小幅晃动会记录散布，不强求精确为零；不会把失败变成0偏差。
- 原点必须是本会话的成功采样点。历史其他会话的点，请恢复原会话，不按名称猜匹配。
- 跨开机/重定位可比较同一地图的历史WP，但必须先完成当前定位检查，报告注明跨会话。
- 手机断线不取消已接受任务；重开只查询，不重发。机器人断电/服务重启期间的未完成任务会标记中断，不能算有效测量。

## 实现和边界

- 原航点作为只读基准；新的5秒采样生成单独任务、证据和图。幂等键＋全局任务锁防重复提交。
- 比较机器人身份、地图内容哈希、参考帧、标定配置及当前定位检查；朝向采用±180°环绕差。
- 标点和复测统一使用既有采样质量规则：位置相对均值离散最多10 cm、姿态离散最多5°。超过3 cm/2°另作“离散较大”提示并保留散布值，不声称厘米级精度。不修改IMU、控制器或切图停稳门限。
- 网页不发运动、停车、重定位或切图命令。5秒结束只结束采样，不是急停。
- 本功能测试中的模拟0偏差不是现场验收；真实回到同一标记的复测仍由操作者完成。

## “检查/确认”按钮为什么不同

- **30秒检查**是只读诊断，不要求先定位正常；仍要求当前机器人/地图会话匹配、定位服务在运行且没有建图任务，以及人工停稳确认。
- **人工叠合确认**不是跳过检查：需本次30秒质量通过，并显示同图实时扫描供人眼核对。
- **Code3/局部定位**：即使位姿消息很新，也不代表匹配回了地图。30秒检查会留下失败原因，不强制变成通过。
- 网页传输等待容差改为8秒，兼容约3秒的实际刷新。后台传感器源时间0.5秒等规则不变，每次操作在机器人端重新核对；断线或超时仍禁用依赖实时状态的按钮。
- 自检的录制依赖失败不再连带阻断只读定位检查和WP；录制仍要满足依赖与存储检查。
