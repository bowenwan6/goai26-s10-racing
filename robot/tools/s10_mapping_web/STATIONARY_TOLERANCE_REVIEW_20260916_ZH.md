## 本轮新增

`stationary_tolerance_review.py` 仅读取本地已保存 ZIP，不导入生产 worker、不连接 ROS、不控制机器人、不写回原始数据。

候选使用连续 5 秒窗口，分开检查：

1. 运动反馈暂定实验包络：X/Y ±0.02 m/s、yaw ±0.02 rad/s。这是待验证候选，不是已标定停稳阈值。
2. IMU 原值峰值保留现有 0.08 rad/s 上限，另检查均值、波动与姿态变化，不减加速度重力，不用正负抵消掩盖摆动。
3. 相对窗口起点的位置变化不超过 0.01 m、姿态变化不超过 1°；不是绝对精度证明。
4. 规划器零命令、无目标、同一服务会话；分话题检查源时间、覆盖、缺口和有限数值。
5. 恒定非零反馈单独警告，不能以消息新鲜证明其估计有效。

所有结果固定带 `activation_allowed:false`。即使 `signal_candidate_pass:true`，也不能用于切图、导航或替换现有保护。

## 尚缺什么

只有静止样本，不能证明该候选能区分真实缓慢移动。Safety System 的失效关闭边界要求先核实反馈有效性，再由现场人员在安全平地完成短动停反例验证；模型测试不替代真机验证。当前没有授权软件自动行走，也没有启动切图、传感器校准或后台录制。

待现场人员确认可以配合后，先准备被动采集，再提示其手柄操作；不要在采集尚未就绪时自行运动来“验证”。未验证前候选不接入放行路径。
